Source Data

Every number we publish traces to public records you can pull yourself. This page holds the source data behind each report, exactly as received or downloaded, along with the live public endpoints we use.

Live public sources (no records request needed)

  • City of Boulder Open Data — "Boulder PD Calls For Service" — Every police call since January 2023, updated daily, including noise complaints, first-officer arrival times, and outcomes.
  • City of Boulder public-safety dashboards — The city’s own dashboards, including rental-property calls for service.
  • Boulder County Assessor property search — Owners of record for every property in the county.

Report source files

October 2025 report

  • Boulder Police dispatch records, Oct 2022 – Oct 2025 (Excel) — The dispatch extract obtained by records request: every noise call for service citywide, with incident number, timestamp, problem type, and address.
  • University Hill impact zone — 2,049 addresses (CSV) — The address list defining the study area, exported from the Boulder County Assessor.
  • Analysis workbook, Oct 2022 – Oct 2025 (Excel) — Every pivot, year table, and top-offender list behind the October 2025 report.

Understanding Noise Pollution in Boulder (September 2026)

  • Complete data package (zip, 4 MB) — Every dataset, analysis script, and figure behind the report, with a claim-by-claim manifest and SHA-256 checksums. The scripts run as shipped and reproduce every number in the report.
  • Package manifest (README) — Per-file provenance, the claim → data → script table, conventions, and licenses.
  • Browse the files with version history — Every file in the package, with the full change history GitHub records.
  • Noise calls for service, Jan 2023 – Aug 2026 (JSON) — Snapshot of the city open-data feed as downloaded Aug. 15, 2026 — 9,961 calls with arrival times and outcomes.
  • Rental-property noise calls, trailing 365 days (JSON) — Exact-address noise calls at licensed rentals, from the city’s rental-property feed.

Notes on the data

Police dispatch records contain incident numbers, timestamps, problem type, and addresses only — no caller information of any kind. A dispatched complaint is a logged resident call, not a finding of violation. A data dictionary describing every file and field is included in the folder.
